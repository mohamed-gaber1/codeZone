# codeZone

Backend API for an online courses platform, built with Node.js, Express and MongoDB.

## Features
- JWT authentication with bcrypt password hashing
- Users and courses management
- File uploads with Multer
- Request validation with express-validator

## Tech stack
Node.js, Express 5, MongoDB (Mongoose), JWT, Multer

## Getting started
```bash
npm install
npm run run:dev
```
Create a `.env` file with your MongoDB URI and JWT secret.
